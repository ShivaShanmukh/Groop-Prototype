THE RESEARCH FACILITY  (Groop prototype)

HOW TO PLAY
  Double-click ResearchFacility.html. It opens in your web browser.
  Use Google Chrome or Microsoft Edge. If it opens in another browser,
  right-click the file -> Open with -> Chrome.
  You need a keyboard and a mouse.

  Everything else (story, objective and controls) is on the start screen.

  Esc pauses. R plays again after a run ends. M mutes the sound.

  ResearchFacility-Playtest.html  the same game, with playtest recording for facilitators (see PLAYTEST.md)
